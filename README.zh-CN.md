# 机械指针

一个 3D 打印的桌面机械指针：SG90 舵机转动 74 齿齿轮，齿轮推动齿条，红色箭头沿 90 mm 刻度上下移动。ESP32 控制舵机，Mac 菜单栏 App 把数据换算成 0–100% 后通过蓝牙发过去。

同一块指针、同一份固件，在 App 里可以切换两种用途：

- **Codex 额度**：显示 Codex 5 小时 / 每周额度还剩多少；
- **游戏指针**：实时识别屏幕上的游戏仪表，变成实体指针。
  - 赛车：速度表、转速表（按档位模拟）、手动挡转速表（读游戏的转速条和档位）；
  - 飞行：速度表、高度表（读滚轮计数器）。

## 功能

- 90 mm 行程，实心面板只有刻度，配大箭头
- ESP32 装在背面小仓里，USB-C 从侧面露出
- 只用 **8 颗 M2 螺丝**：面板挂钩、抽拉式盖板、压入式箭头
- 所有零件**不需要支撑**
- Mac 菜单栏 App：Codex 额度 / 游戏指针两种模式、测试、数值校准、舵机转速调节、开机启动、中英双语

## 游戏指针

在 App 的「设置 → 模式」里选「游戏指针」，然后到「游戏」页：

1. **选游戏类型和表盘**

   | 游戏 | 表盘 | 读什么 |
   |---|---|---|
   | 赛车 | 速度表 | 屏幕上的车速数字 |
   | 赛车 | 转速表（模拟） | 车速数字，按五挡换挡表模拟发动机转速 |
   | 赛车 | 手动挡转速表 | 游戏自己的转速条和亮着的档位 |
   | 飞行 | 速度表 | 速度滚轮计数器（如 `00897`） |
   | 飞行 | 高度表 | 高度滚轮计数器（如 `00049`） |

2. **框选区域**：点「框选数字区域（3 秒后）」，切回游戏，用鼠标框住要读的数字。
   - 只框数字：不要框到档位 N/D，也不要框到旁边刻度上的数字；
   - 手动挡转速表要框两块：转速条从左端到右端，档位行从第一个档位到最后一个；
   - 每个表盘的区域分开保存；
   - 全屏游戏可以直接在游戏里点菜单栏图标框选。

3. **设置满格值**：满格速度、满格转速、满格高度、转速条右端的转速，按游戏实际情况填。

第一次使用要在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」里允许 **机械指针**，允许后重新打开 App。

### 识别是怎么做的

- **截屏**：用 ScreenCaptureKit 只截框选的那一小块，每秒 30 帧。
- **数字**：用 macOS 自带的 Vision OCR 识别，快速模式每帧约 4–8 ms。
  - 先按字形间的空白数出画面里有几个字，读出的位数比字形少（比如 `117` 被读成 `7`），就用精确模式重读同一帧（约 20 ms）；
  - 读数和当前值相差太多时也会复核。复核确认是真的急停，就立即跟过去，不会额外等待。
- **飞行计数器**：会记住计数器的固定位数，再加上 3 帧中位数和自适应平滑（One-Euro），所以不跟着滚轮跳动，爬升、俯冲时也能跟上。
- **转速条和档位**：直接分析像素，不用 OCR，每帧约 1 ms。转速打到红线、转速条白红交替闪烁时，指针保持满格。
- **发送**：每秒最多 40 条，用 Write Without Response，不等回复。
- **转速表（模拟）**：怠速抖动、起步半离合、急加速晚升挡 / 缓加速早升挡、升挡下冲、降挡补油、发动机抖动、断油回弹。

快速和精确两种识别读得不一样的画面会存到 `~/Library/Application Support/MechanicalGauge/ocr-samples/`，方便排查，在「游戏」页可以直接打开这个文件夹。

## 打印

PLA，0.2 mm 层高；齿轮、齿条 4 道墙，其余 3 道。导入时保持 100% 比例，零件已经按打印方向摆好。

**所有零件都关闭支撑。** 悬空处都是短桥接（≤ 11 mm）或 45° 斜面。如果加了支撑，支撑会长进刻度槽、舵盘槽、齿条齿面和盖板导槽里，拆不干净就装不上。

## 接线与供电

| SG90 线 | ESP32 |
|---|---|
| 棕（地） | **GND** |
| 橙（信号） | **D13** |
| 红（电源） | **5V / VIN**（板子插 USB 时这个脚有 5V 才行）；没有的话接 **3V3** |

- 不要把舵机 3 针插头直接插在排针上：引脚顺序对不上，会把舵机电源接反。要用 3 根杜邦线分开接。
- **供电要够**：舵机启动和高速转动时电流很大，Mac 的 USB 口可能带不动。带不动时的表现是舵机只有齿轮声、箭头不动，ESP32 也不再响应。换成 USB 充电头或充电宝供电就好了；也可以在红、棕两线之间并一个 470～1000 µF 电容。
- 用充电宝供电时，Mac 通过蓝牙控制指针。烧录固件时再临时接回电脑。

## 装配

1. 安装座上放两片 1.0 mm 垫片，舵机从正面放入，舵机线从立柱下的出线口穿出，用 2 颗 M2×8 固定。
2. 先把 3 根杜邦线插到 ESP32 上（USB 那一端）。把背仓底座贴到后壳背面，ESP32 元件面朝外、排针朝里，USB 端的两个孔套进定位销，排针和杜邦线一起穿过长槽。2 颗 M2×12 穿过板子和背仓，拧进后壳。
3. 盖板从天线那一端推进去，"咔"一声卡住。
4. 在壳内把杜邦线接到舵机线上。
5. 在 App 里点"回中 1500"。
6. 齿条放进导轨；十字舵盘放进齿轮的槽里，盖上压盖，拧 2 颗 M2×6；然后把齿轮套到舵机轴上，拧上舵盘中心螺丝。
7. 面板：先往上错开约 3.5 mm 放下（滑槽套过指针颈，中间孔套住齿轮轴），再往下推 3.5 mm，让底部挂钩卡住，最后拧上顶部 2 颗 M2×6。
8. 把箭头压到指针颈上，松的话点一滴胶。
9. 在 App 的「校准」页校准 0% 和 100%。

## 固件

用 Arduino IDE（ESP32 开发板支持包 3.x）打开 `firmware/MechanicalGaugeBLE/MechanicalGaugeBLE.ino`，开发板选 **ESP32 Dev Module**，并设置 **Flash Mode DIO、Flash Size 4MB、Upload Speed 115200**。用默认的 QIO / 921600，有些 FT232 板会读不到 Flash。

```bash
arduino-cli compile --upload --fqbn "esp32:esp32:esp32:FlashMode=dio,FlashSize=4M,UploadSpeed=115200" -p /dev/cu.usbserial-XXXX firmware/MechanicalGaugeBLE
```

固件只认百分比，所以 Codex 和游戏两种模式用的是同一份固件，切换模式不用重新烧录。为了兼容已经烧录的板子，蓝牙设备名仍是 **CodexGauge**。命令（蓝牙或 USB 串口 115200 都可以）：

| 命令 | 作用 |
|---|---|
| `STATUS` | 查询校准、脉宽、转速 |
| `P <µs>` | 直接设定脉宽（500–2500），校准用 |
| `CAL <0%脉宽> <100%脉宽>` | 保存校准 |
| `Q <百分比>` | 显示数值（需先校准） |
| `T <百分比>` | 测试位置（需先校准，不算作真实数据） |
| `SPEED <°/秒>` | 舵机转速 10–1000，保存（V5 固件；旧版 V4 最高 400） |
| `STALE` / `OFF` | 标记数据过期 / 放松舵机 |

校准值和转速保存在 Flash 里，断电不丢；刷新固件也不会清掉。

## Mac App

打开 `release/MechanicalGauge.dmg`，把 **机械指针** 拖进「应用程序」。App 是本地签名、没有经过苹果公证，所以第一次打开要**右键 → 打开**。系统询问时，允许它使用蓝牙；用游戏指针时还要允许屏幕录制。

- **菜单栏**：Codex 模式显示剩余百分比；游戏模式显示速度、转速或高度。可以在设置里打开指针图标。
- **菜单面板**：Codex 模式显示 5 小时 / 每周额度和重置时间；游戏模式显示读数、档位和识别状态。另有「自动同步 / 实时跟随」开关。
- **设置与校准**窗口：
  - **游戏**：游戏类型、表盘、满格值、框选区域、识别预览；
  - **测试**：拖动百分比、全程扫描；
  - **校准**：直接填写脉宽数值，或者微调后一键记录两端位置；
  - **设置**：模式（Codex 额度 / 游戏指针）、显示哪个额度、舵机转速、刷新间隔、语言、菜单栏图标、开机启动；
  - **日志**：命令和板子的回应。

在测试页或校准页操作时会自动暂停同步，做完记得在菜单里重新打开「自动同步 / 实时跟随」。Codex 模式需要 Mac 上已安装并登录 Codex 命令行（ChatGPT 桌面版自带）。

自己编译（只需要命令行工具，不需要 Xcode）：

```bash
cd macos-app && ./build.sh
```

自己编译出的 App 签名每次都不一样，macOS 可能会让之前给的屏幕录制权限失效。遇到这种情况，在系统设置里删掉「机械指针」，再重新授权。

## Python 命令行工具

```bash
cd hardware/CAD

python build_v5.py && python check_v5.py && python sweep_v5.py && python assembly_path_v5.py
```
